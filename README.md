# Minimal Hyprland Setup

> Personal spin on a minimal Hyprland configuration.

A clean, modular desktop environment built on **Arch Linux** and **Hyprland**, featuring a custom-styled **Waybar**, hardware controls, and application launchers.

## 🛠️ Prerequisites & Dependencies

Ensure the following packages are installed on Arch Linux:

```bash
sudo pacman -S hyprland waybar playerctl python-gobject python-dbus ddcutil nm-connection-editor swayosd
```
